# Architectural Decision Records

Per Engineering Standards §12, every architectural decision made during Phase 2
is recorded so a developer joining this project years from now can understand
*why* a choice was made without asking the original team directly.

The full ADR registry (38 entries, ADR-001 through ADR-038), each with a
one-line decision, its rejected alternatives, and a pointer to the source
document containing the complete Context → Decision → Alternatives →
Consequences reasoning, lives in:

**`Phase2_Engineering_Blueprint_Freeze.md`, Section 11.**

That document — not a duplicate copy here — is the authoritative ADR index.
This file exists only so `docs/adr/` isn't an empty, misleading folder for
anyone browsing the repository structure directly.
